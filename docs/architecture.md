# 系统说明

一个挂在 QQ 群里的拟真聊天机器人。它不查面板、不抢云崽的活，目标只有一件：像群里一个正常人那样接话。

入口 `bot.py`，提示词在 `prompts.py`，表情包索引在 `meme_catalog.py`。

## 一条消息进来之后

1. 校验群在白名单里，跳过自己发的消息。
2. 实时查一次机器人是否被禁言。禁言期间直接丢弃，不发请求。
3. 清洗 CQ 码，展开引用和合并转发，遇到抖音、B 站、小红书短链就抓标题和简介。
4. 依次拦截：云崽指令（`#`、`*`、`%`、`~` 开头等）、提示词注入、内置小游戏、管理员管理指令、睡眠时段。
5. 判断这次要不要说话：
   - 被 @、被引用回复、或者处在追问窗口里，立即回；
   - 否则走主动插话门控（本地规则 + 冷热场权重 + 冷却），不通过就静默。
6. 拼 prompt 调 DeepSeek-V3。模型可以回 `[PASS]` 表示不插话，也可以带 `[MEME:情绪]` 要求配图。
7. 回复按标点和长度切成 1~2 条，带打字延迟依次发；要配图时，文字发完再单独发一张。
8. 把自己的回复写回时间线，异步更新这个群友的好感度和印象。

## 会话与追问

- 每个群一条时间线，最多 8 条，5 分钟没人说话就清空。
- 普通群聊只把当前这句发言交给模型，不带滚雪球历史，既避免接错人，也省 token。root 模式才带完整时间线。
- 被 @ 或引用后开一个 5 分钟窗口，窗口内最多免 @ 追问 5 次；再次 @ 会重置配额；明确 @ 别人则主动退出。

## 好感度

- 范围 0~100，按群隔离，初始 50。同一个人在不同群互不影响。
- 每次成功回复后异步判定，模型返回 -5~+5 的 delta 和一个十字以内的印象。
- 判定前先过滤：少于 4 字、纯符号、复读、开黑报点这一类直接跳过，不发请求。
- 同一个人 60 秒内只判一次，中间的话攒起来合并成一句再判。
- 印象超过 6 条或总字数超过 120 字时自动压成一条。
- 戳一戳固定 +1，不经过模型。

## 表情包

- 图库在 `meme-pack/memes/`，索引 `meme-pack/memes_catalog.json` 是离线打的一次标，共 138 张，每张带画面描述、图上文字、情绪和关键词。
- 运行时只读索引，不扫目录，也不调视觉模型。
- 给模型的说明只有一句：想配图就在句末加 `[MEME:情绪]`，情绪限卖萌、得意、嘲讽、震惊、愤怒、委屈、无奈、干饭八个桶。
- 选图顺序：标签对应的桶 → 回复文本命中关键词 → 老的随机逻辑兜底。单张超过 1.2MB 跳过，最近发过的 12 张不重复。
- 标签在切段发送前、写回上下文前、私聊发送前都会剥掉；模型漏写右括号的残渣一并清理。

## 看图

- 群友发图时先只记下图片地址，不立刻调模型。
- 等机器人真要被 @ 或插话时，才取最近两分钟内那张图的摘要，拼成一句「谁刚发了张图：内容」带进消息。
- 同一张图只调一次，摘要进内存缓存。用的是 SiliconFlow 的 `Qwen/Qwen3-VL-8B-Instruct`，原来写的 Qwen2-VL 已经下架，接口会直接返回 400。

## 戳一戳

- 普通群友戳一下，从本地语料随机回一句，不调 API。
- root 模式下才真的问模型，因为那里要判断主人有没有活安排。
- 回戳前有单人冷却，防止被连戳刷屏。

## 频控与夜间

- 单群 60 秒最多 8 条，超出排队或延时，避免触发腾讯风控。
- 机器人被禁言时不发请求。
- 01:00~07:00 是睡眠期。群友 @ 会得到一句梦话，旁听消息直接忽略；主人有唤醒词。

## 和云崽共存

- 同一个 QQ 同时挂着云崽（TRSS-Yunzai），负责原神、星铁、绝区零、鸣潮、异环的面板和抽卡。
- 带指令前缀的消息全让给云崽，AI 保持静默。
- 群友问「怎么查」「怎么绑定」时才把指令清单拼到消息末尾，平时这两千多字符不出现。

## Token 花在哪

改造前后各测过一次：

| 场景 | 输入 tokens |
| :--- | :--- |
| 普通闲聊（改造前） | 约 2188（当天均值） |
| 普通闲聊（现在） | 约 1034 |
| 群友问面板用法 | 约 2420（临时带上指令清单） |
| 好感度判定（改造前） | 289 |
| 好感度判定（现在） | 151 |

省下来的部分来自三处：System Prompt 从 3236 字符压到 1260 并保持静态；热梗只在命中时注入一两条，不再整包塞 100 个词；游戏指令清单按需加载。

关于前缀缓存：SiliconFlow 的返回里有 `prompt_cache_hit_tokens`，但实测命中阈值在 6.6k tokens 上下，一千出头的请求进不了缓存窗口。静态化是为了少做重复计算、方便前后对比，别指望账单因此打折。

## 配置

密钥和连接信息全部走环境变量，仓库里只有占位符。

| 变量 | 说明 |
| :--- | :--- |
| `NAPCAT_WS_URL` | OneBot 11 的 WebSocket 地址 |
| `BOT_QQ` | 机器人自己的 QQ |
| `ADMIN_QQ` | 管理员 QQ，拥有 root 模式 |
| `WHITELIST_GROUPS` | 启用的群号，逗号分隔 |
| `DEEPSEEK_API_KEY` | 模型 API 密钥 |
| `DEEPSEEK_API_URL` | 兼容 OpenAI 协议的接口地址 |
| `DEEPSEEK_MODEL` | 模型名，默认 `deepseek-ai/DeepSeek-V3` |
| `YUNZAI_OTHER_YAML` | 云崽白名单文件路径，用于同步群开关 |

`group_configs.json` 按群存开关：`mode`、`enable_interject`、`interject_prob`、`enable_sleep`、`enable_poke`、`enable_games`、`enable_search`、`enable_yunzai`。没写到的群用默认值。

## 指令

| 指令 | 谁能用 | 干什么 |
| :--- | :--- | :--- |
| `/root` | 管理员 | 切成技术模式，长回复不分段 |
| `/user` | 管理员 | 切回日常闲聊 |
| `/new` | 管理员 | 清掉当前群或私聊的短期上下文，记忆不动 |
| `/new all` | 管理员 | 清掉所有群的短期上下文 |
| `/stop` | 管理员 | 打断正在生成的请求，清空排队 |
| `/memory` | 所有人 | 看自己在当前群的好感度和印象 |
| 戳一戳 | 所有人 | 回一句，同时开 5 分钟追问窗口 |

管理员还能直接说人话改数据，比如「把 123456 的好感度调成 80」「清掉 123456 的记忆」。
