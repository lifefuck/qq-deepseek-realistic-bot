## 一、项目愿景与去人机味核心哲学

传统 QQ 群聊机器人大多存在三大致命痛点：
1. **“客服感”极重**：动辄“您好”、“有什么可以帮您”、“作为人工智能我建议...”，一开口群友就失去聊天的欲望；
2. **认错人与被白嫖 Token**：简单的滚雪球式历史记录拼接，不仅导致 Token 消耗指数级暴涨，而且多人在群里交叉说话时，AI 经常“张冠李戴”，接错话题；
3. **脆弱且缺乏边界**：容易被群友诱导破防、复读旧账、被禁言后还在后台盲目消耗大模型 API，或者与群内的其他功能机器人（如查原神/星铁面板的云崽）撞车刷屏。

**本项目的设计哲学：**
- **不做高高在上的工具，只做群里真实活着的“沙雕群友”**。
- **极短发言、零句号、零小作文、自带情绪表情包、有脾气有傲娇、绝不当受气包**。
- **深度工程优化**：群聊轻量未读机制、按群隔离的 Galgame 好感度记忆、60 秒免 @ 追问窗口、实时禁言短路拦截、双底座前缀分流防撞车。

## 四、十大小巧思与工程创新设计

### 1. 轻量未读消息机制（Token 消耗暴跌 90% + 彻底解决认错人）
* **痛点**：传统群聊机器人把过去 20 条消息无脑拼接进 Prompt。群友 A 正在跟群友 B 吵架，群友 C 突然 @ 机器人，模型看了一大坨无关聊天，非常容易张冠李戴，误以为群友 C 在跟它聊 A 和 B 的事，胡乱插话。
* **巧思实现**：
  * 在群聊日常模式下，不滚雪球传递整个群历史；
  * 模型调用时，**仅传入当前群友触发的那条发言（或直接相关的引用回复）**；
  * 短期时间线仅用于本地代词消解与上下文防重复。
  * **成果**：上下文极度纯净，单次群聊调用 Token 控制在 100~300 以内，且机器人永远精准对应提问者本人。

---

### 2. 按群严格物理隔离的 Galgame 好感度与动态画像系统
* **痛点**：群友在“技术交流群”里可能是正经工程师，在“二次元摸鱼群”里可能是纯纯的乐子人；如果全局记忆混在一起，容易造成人设串味甚至隐私泄露。
* **巧思实现**：
  * `user_memories.json` 采用两级字典架构：
    ```json
    {
      "123456789": {
        "12345678": {
          "nickname": "群友A",
          "favor": 55,
          "traits": ["爱抽卡", "熬夜冠军"],
          "updated_at": 1729780000
        }
      },
      "private": { ... }
    }
    ```
  * 同一个 QQ 号在群 A 的好感度和群 B 彼此独立、互不干扰；
  * **自然 baseline 设定**：所有用户（包括主人）默认好感度基准设为 50，允许随互动正常浮动（0~100）。好感度高时展现傲娇口嫌体正直，好感度极低（0~20）时毒舌嫌弃；
  * **异步画像提取**：模型在回答完毕后，后台通过 `asyncio.create_task` 异步解析提问意图提取用户画像，零阻塞、零延迟发信。

---

### 3. 60 秒免 @ 专属追问窗口（动态 Debounce）
* **痛点**：群聊中必须每次都 @ 机器人显得极其死板；但如果不加限制任何话都接，群聊又会被机器人无休止刷屏打扰。
* **巧思实现**：
  * 引入 `user_follow_up_expire[(group_id, user_id)] = time.time() + 60`；
  * 一旦群友通过 `@机器人` 或回复机器人开启了对话，系统为该群友启动**60 秒专属追问窗口**；
  * 在接下来的 60 秒内，该群友在群里说的话，即使不再 @ 机器人，机器人也会判定为连续追问并自然接话；
  * 超出 60 秒未说话，追问窗口自动关闭，重新回到必须 @ 的静默待命状态。每个群友的窗口彼此独立，互不影响。

---

### 4. 禁言状态零消耗实时探测（省 Token 神器）
* **痛点**：机器人一旦被群管理员禁言（单人禁言或全员禁言），群友如果继续在群里疯狂 @ 它，未加防护的 Bot 会傻傻地一直在后台调用 DeepSeek API，算出了回答却发不出来，白白烧光主人的钱包。
* **巧思实现**：
  * 在消息处理入口处，实时调用 OneBot 11 的 `get_group_member_info` 检查 `ban_expire_time`；
  * 命中禁言的一瞬间，**直接在最外层 return 丢弃，坚决不发起任何 API 请求**，一个 Token 都不浪费。

---

### 5. 绝对静默指令与心理独白拦截（`[PASS]` 网关）
* **痛点**：让大模型“根据语境自行决定要不要接话”时，大模型经常会在输出里写一堆废话独白，例如：“*（根据人设，此时我应该保持沉默不插话）*”，并把这句话当成聊天发到群里，产生巨大“人工智障”感。
* **巧思实现**：
  * 提示词中规定：如果认为无需接话，必须严格输出 `[PASS]`；
  * 代码层构建了拦截管道：
    ```python
    if "[PASS]" in reply or any(kw in reply for kw in ["保持沉默", "保持静默", "无需回复", "不便插话", "选择沉默"]):
        logger.info("模型决定静默，拦截丢弃")
        return
    ```
  * 双重过滤彻底终结内耗自语。

---

### 6. 打字机拟真延迟与智能分段发送（去机器味交付）
* **痛点**：机器人的 API 回复往往是整段瞬间秒回，一眼假；且遇到长内容时直接砸一段长文本，视觉压迫感极强。
* **巧思实现**：
  * **阅读打字延迟模拟**：根据回复字数动态计算打字时间（`0.03s ~ 0.08s / 字`），先 sleep 模拟思考和手机输入，再发出；
  * **智能断句分段发信**：遇到换行、逗号或句号切分逻辑，分多条气泡依次弹出，完美复现真人在 QQ 连续发多条短消息的打字习惯。

---

### 7. 大肥鱼专属情绪表情包引擎（Meme Engine）
* **巧思实现**：
  * 本地挂载表情包图库（`/meme-pack/memes/`），按情绪和领域打上分类：
    - `_genshin`: 二次元/米家梗
    - `_stock` / `_green` / `_red`: 股市/A股/发财/吃瘪
    - `_laugh`: 疯狂嘲笑/乐子
    - `work`: 加班打工
    - `angry`: 炸毛反击/咬人
  * 根据当前回复文本与群友输入的情绪关键词，以概率触发动态图文协同：文字发完后，附带一张最贴切的大肥鱼本地表情包，社交互动感瞬间拉满。

---

### 8. 戳一戳（Poke）动态好感度响应与防刷 CD
* **巧思实现**：
  * 监听 OneBot 11 的 `notify.poke` 事件；
  * 检查 `target_id == BOT_QQ`；
  * 带有防恶意狂戳冷却（单人 10 秒 CD）；
  * 戳机器人时，根据该用户当前的好感度动态回复不同语气的反应（低好感度回击：“再戳把你鱼鳍拧下来！”，高好感度娇羞傲娇：“哼，手痒了是不是？”）。

---

### 9. 状态重置与隔离：`/new` 与 `/stop` 机制
* **巧思实现**：
  * **`/new` 指令**：仅清空运行时的短期聊天上下文时间线（`group_timelines[group_id].clear()`），**长期记忆 `user_memories.json` 完好无损保留**；
  * **`/new all`**：一键重置所有群的时间线；
  * **`/stop` 指令**：一键打断所有正在运行中的 DeepSeek 异步请求和 Debounce 定时器，遇到卡壳或群友刷屏攻击时可瞬间刹车。

### 10. 管理员模式热切换（Root vs User）
* **巧思实现**：
  * 私聊发送 `/root`：AI 切换为懂你的技术老搭档与私人秘书，懂口语黑话与真实意图，沟通利落、直击痛点，支持长代码、架构分析与部署指导；

  * 模式状态保存在进程中，随心自由切换。

## 五、多 Bot 共存与游戏底座（云崽）防撞车方案

这是本项目最关键的工程解耦设计：**在不侵入云崽源码的前提下，让 AI 与游戏 Bot 完美共存同一个 QQ 账号**。

### 1. 物理拓扑与转发路由
* **轻量接入端（电视盒子/边缘设备）**：运行 NapCat，负责 QQ 协议连接；
  - 正向 WebSocket（`:3001`）提供给 `qq-deepseek-bot`；
  - 反向 WebSocket（连接 `:2536`）提供给 `trss-yunzai`。
* **重计算端（MiniPC x86 主机）**：
  - 运行 `qq-deepseek-bot`（负责 AI 逻辑与 API 交互）；
  - 运行 `trss-yunzai` + Redis + 喵喵插件（负责高清面板 Chromium 渲染）。

### 2. 双向零撞车网关规则
为了防止两者抢答、争夺指令或死循环，在 `bot.py` 的消息最前端设立了**双重静音关卡**：

1. **机器人自身回环过滤**：
   ```python
   if sender_id == BOT_QQ:
       return  # 云崽发出的所有面板图、抽卡图，AI 秒级丢弃，绝不上报给大模型
   ```
2. **符号与免前缀游戏指令全量拦截（`is_game_or_yunzai_command`）**：
   - **符号前缀全覆盖**：`#`、`*`、`!`、`?`、`%`、`$`（包括中文全角 `井`、`＊`、`！`、`？`、`％`、`￥`）开头的消息，AI 机器人直接 `return` 绝不插话；
   - **常用免前缀二次元词条拦截**：`雷神面板`、`流萤遗器`、`抽卡记录`、`今日素材`、`十连`、`单抽`、`深渊战绩`、`绑定uid` 等，代码层正则直接识别跳过；
   - **私聊 Cookie 过滤**：群友私聊发送米游社 Cookie（带 `_MHYUUID`）时，AI 自动保持沉默，留给云崽独立识别绑定。
3. **Prompt 协同告知**：
   - 在 AI 人设中明确告知“本机接入了云崽游戏 Bot”，即使群友用自然语言提及查面板，AI 也会礼貌告知群友去呼叫云崽，绝不编造虚假数据。

### 2. 常用管理指令清单

| 指令 | 适用场景 | 作用 |
| :--- | :--- | :--- |
| `/root` | 管理员私聊 / 群聊 | 切换到懂口语黑话的技术老搭档人格（干脆利落、直击痛点） |
| `/user` | 管理员私聊 / 群聊 | 切回沙雕傲娇蓝发小鲸鱼娘人格 |
| `/new` | 群聊 / 私聊 | 重置当前群/私聊的短期聊天历史（保留记忆与好感度） |
| `/new all` | 群聊 / 私聊 | 一键重置所有群的聊天历史 |
| `/stop` | 群聊 / 私聊 | 立即打断当前所有正在思考的大模型请求 |
| `/compress` | 群聊 / 私聊 | 立即压缩当前上下文时间线 |
| `/b` | 群聊 | 一键汇总本群最近聊天的核心要点并生成简报 |
| `/user <qq> favor <0-100>` | 管理员 | 手动调整指定用户的专属好感度数值 |
| `/user <qq> del` | 管理员 | 清除指定用户的长期特征画像与记忆 |
