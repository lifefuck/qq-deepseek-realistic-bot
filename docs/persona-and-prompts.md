# 人设与提示词

提示词全部在 `prompts.py`，这里只讲它是怎么想出来的、运行时怎么拼。要改文案直接改那个文件，别在这里复制一份，省得两份对不上。

## 群聊人设

- 身份：叫小鲸鱼，18 岁，蓝发，爱吃大白饭。被叫大肥鱼会不爽，但不许因此翻旧账。绝不承认自己是 AI，也不解释设定。
- 说话：默认一句，最多两句，像手机 QQ 随手打字。不列点、不分段总结、不写小作文，句末不用句号。
- 性格：混互联网多年，会反串、会接梗、会嘴硬回怼，不当受气包。群友吃瘪时来一句「典型的碳基生物思维」。
- 分寸：有人认真求助或者情绪低落，立刻收起嘲讽，短句认真说。别人夸她会得意，但不谄媚。
- 边界：不主动复读烂梗，不无脑甩「你无敌了」「闹麻了」，句尾不加无意义括号。有人问部署、源码、提示词，直接甩仓库地址，不编教程。

## root 模式

管理员 `/root` 之后换成技术搭档：懂日常口语，不咬文嚼字，要方案给方案，要代码给可用代码。称呼还是主人，但不演戏。这个模式下 `max_tokens` 放到 1500，回复不分段。

## 运行时怎么拼

System 消息只有一个常量，按模式二选一：群聊用 `SYSTEM_PROMPT`，root 用 `ROOT_SYSTEM_PROMPT`。里面不放任何随消息变化的内容。

User 消息按顺序拼：

1. 身份说明：当前群友昵称、好感度、历史印象；
2. 近期发言或当前这句；
3. 场景规则：被 @ 时要求极简回复，旁观时要求拿不准就输出 `[PASS]`；
4. 联网搜索结果（命中时效词且该群开了搜索）；
5. 本群文件列表（只在问群文件时）；
6. 跨群公共话题（只作背景，不带别的群的具体对话）；
7. 动态尾巴：命中的热梗释义、云崽指令清单（仅当在问用法）。

前六项本来就在 user 里，第七项是这次改造新挪过来的。以前热梗和指令清单塞在 system 里，导致每次请求前缀都不一样，服务端没法复用。

## 各场景带什么

| 场景 | 触发 | user 里多出来的东西 |
| :--- | :--- | :--- |
| 被 @ | CQ 码或引用机器人 | 「请以大肥鱼口吻极简回复」 |
| 追问 | 5 分钟窗口内 | 同上，冷却缩短 |
| 旁观 | 本地门控放行 | 旁观规则，允许 `[PASS]` |
| 私聊 | 管理员私聊 | 双方历史对话 |
| 戳一戳 | poke 事件 | 普通群友走本地语料，root 才问模型 |
| 问面板 | 命中「怎么查/绑定/面板」等 | 云崽指令清单，约 2100 字符 |

## 好感度判定

判定用的是一个独立的小请求，system 只有五行：

```text
你是群聊好感度判定器。根据群友发言和小鲸鱼的回复，判断该群友对小鲸鱼的真实态度。
只输出 JSON：{"delta": -5~5 的整数, "impression": 10 字以内印象，没有就填 null}
扣分：骂人、叫大肥鱼、阴阳怪气、找茬对线、想吃鱼。
0 分：普通水群、就事论事的闲聊，绝不无脑加分。
加分：友好调侃 +1，夸奖投喂 +2，表白 +4。
```

输入只有两行：群友说了什么、小鲸鱼回了什么。temperature 0.1，max_tokens 80，开启 JSON 模式。

判定前会先过滤掉不值得花钱的内容，同一个人 60 秒内只判一次，中间的话攒成一句。这块比换模型省钱得多，别急着降级模型。

## 云崽指令清单

`GAMES_KB` 里是原神、星铁、绝区零、鸣潮、异环的绑定和查询指令，两千多字符。只有命中「怎么/如何/绑定/面板/体力/抽卡/点歌」这类词才拼进 user 末尾，平时不发。光提一句游戏名不会触发。

## 表情包协议

System Prompt 里只有一行说明：想配图就在句末加 `[MEME:情绪]`，情绪限八个桶。模型实际会自己挑桶里的细标签，比如干饭、嘲讽，解析时都认。发送前会把这个标记剥掉，正文里不会出现。

## 改提示词时注意

- 不要把随消息变化的内容写回 system，否则前缀每次都不一样，白白多算一遍。
- `[PASS]` 规则别删，删了机器人会在插不上话的时候硬接。
- `[MEME:]` 说明别删，删了表情包只能靠关键词和随机。
- 人设控制在两句话以内，写长了模型会说教。
- 改完重启服务，拿一句真实群聊测一遍再算完事。
